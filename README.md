🌱 FarmShield – Intelligent Crop Protection

📌 About the Project

FarmShield is a smart agriculture software prototype designed to demonstrate how crops can be protected from extreme weather conditions and unwanted grass. The project provides an interactive dashboard where users can simulate heavy rain, extreme heat, and weed detection to visualize different crop protection responses.

Our goal is to promote smarter farming practices and support the idea of healthier crops through technology.

🎯 Objectives

- Demonstrate crop protection responses to heavy rainfall.
- Visualize protective canopy deployment during extreme heat.
- Identify unwanted grass using visual detection markers.
- Simulate the removal of detected weeds.
- Provide an interactive dashboard for monitoring field conditions.

✨ Features

🌧️ Heavy Rain Protection

Simulates heavy rainfall and displays a protective canopy over the crop field.

☀️ Extreme Heat Protection

Simulates high-temperature conditions and visualizes canopy deployment to protect crops from direct heat exposure.

🌿 Unwanted Grass Detection

Highlights unwanted grass within the crop field using visual markers.

✂️ Weed Removal Simulation

Allows users to interact with the dashboard and simulate removing detected unwanted grass.

📊 Interactive Dashboard

Displays field condition indicators, temperature, rainfall level, soil condition, and system response messages.

🛠️ Technologies Used

- React.js – User interface and interactive components

- CSS – Styling, animations, and field visualization

🚀 Getting Started

Prerequisites

Install Node.js and npm on your computer.

Installation

1. Clone the repository:
   
   git clone https://github.com/rukminirupa/FarmShield.git

2. Navigate to the project directory:
   
   cd FarmShield

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL displayed in your terminal, usually "http://localhost:5173/".

Production Build

To build the project for deployment, run:

npm run build

The production-ready files will be generated in the "dist" directory.

🌾 Project Workflow

1. Open the FarmShield dashboard.
2. Select normal conditions, heavy rain, extreme heat, or unwanted grass detection.
3. Observe the corresponding field visualization and dashboard updates.
4. In weed detection mode, use the removal button to simulate clearing the detected weeds.
